# ربات بدون Claude Code — راهنمای مالک

*۱۵ سپتامبر ۲۰۲۶*

ربات برای کار روزانه به هیچ‌کس نیاز ندارد. کار شما فقط **خواندن تلگرام** است.

## چه چیزی خودکار است

| کار | زمان | چه می‌کند |
|---|---|---|
| معامله روی ۷ حساب | هر چرخه | تصمیم، سفارش، استاپ، محافظ‌های ریسک و پراپ |
| انتخاب مغز | هر روز ۰۶:۲۰ UTC | اگر مغزی ۱۰۰ پوزیشن سودده داشت، حداکثر هفته‌ای یک حساب را عوض می‌کند و در تلگرام خبر می‌دهد |
| هشدار چرخهٔ متوقف | هر ۱۵ دقیقه | اگر یک کار زمان‌بندی‌شده دو نوبت اجرا نشده، تلگرام |
| ری‌استارت کانتینر خراب | هر ۵ دقیقه | کانتینر unhealthy را یک بار ری‌استارت و خبر می‌دهد |
| نگهبان متاتریدر | هر ۵ دقیقه | جلوی حلقهٔ به‌روزرسانی LiveUpdate را می‌گیرد |
| پشتیبان دیتابیس | هر شب ۰۳:۱۵ | پشتیبان + آزمون بازیابی؛ اگر شکست خورد، تلگرام |
| پاک‌سازی دیسک | هر شب ۰۲:۳۰ UTC | کش build را کم می‌کند |
| گزارش روزانه / هفتگی | ۰۳:۰۰ UTC / دوشنبه | خلاصه در تلگرام |

## وقتی پیامی آمد

| پیام تلگرام | معنی | کار شما |
|---|---|---|
| «امروز» (گزارش روزانه) | همه‌چیز عادی | هیچ |
| «انتخاب مغز» با «اعمال شد» | ربات مغز یک حساب را عوض کرد | هیچ. اگر نخواستید، از صفحهٔ حساب در سایت مغز قبلی را برگردانید (در پیام نوشته شده) |
| «container restarted» | یک بخش گیر کرده بود و خودش درست شد | هیچ |
| «چرخهٔ متوقف» یا «container still unhealthy» | مشکلی که ری‌استارت حلش نکرد | یک روز صبر کنید؛ اگر پیام تکرار شد، به یک برنامه‌نویس بدهید (بخش آخر) |
| «backup failed» یا «evidence failed» | پشتیبان یا یادداشت آمادگی نوشته نشد | اگر فردا هم آمد، به برنامه‌نویس بدهید. «evidence» مهم‌تر است: بدون آن سفارش‌ها بسته می‌شوند |
| **هیچ پیامی بیش از ۲ روز** | سرور یا تلگرام قطع است | سایت را باز کنید؛ اگر باز نشد، از پنل OVH سرور را Reboot کنید |

## کارهایی که از سایت می‌شود کرد

- عوض کردن مغز یا ریسک هر حساب (صفحهٔ حساب‌ها)
- دیدن موجودی، پوزیشن‌ها و گزارش‌ها

## چیزهایی که هرگز خودکار نمی‌شوند (عمداً)

- **بالا رفتن ریسک.** ربات فقط کم می‌کند.
- **حساب پول واقعی.** سوییچ جداست و خاموش است.
- **انتشار کد جدید.** وقتی کسی کد عوض نمی‌کند، چیزی برای انتشار نیست؛ سرور همان نسخهٔ تست‌شده را اجرا می‌کند.

## اگر روزی برنامه‌نویس لازم شد

این سه چیز را به او بدهید:

1. همین فایل و `docs/STATUS.md`
2. آدرس سرور `178.33.150.51` و دسترسی SSH
3. پیام تلگرامی که آمده

اولین دستوری که باید روی سرور بزند:

```bash
docker exec molidotrade-collector-1 python -m app.workers.health_report
```

و لاگ‌های خودکار: `/var/log/molido-autoheal.log`، `/var/log/molido-updater-guard.log`،
`/var/log/molido-backup.log`، `/var/log/molido-checkpoint.log`.
