# MOLIDO DESIGN
Inspect the existing design system before changing it. Preserve product identity and consistency. Verify responsive behavior, typography, spacing, layout, forms, states, keyboard/focus, accessible names, contrast, motion, touch targets, loading/error/empty states, and runtime/console issues. Use Impeccable for deep visual/design direction; use Human E2E for behavioral verification. Do not create decorative complexity that harms usability or performance.
