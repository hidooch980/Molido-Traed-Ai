# MOLIDO PERFORMANCE
Measure before optimizing. Identify the actual bottleneck, make the smallest safe change, measure again, and verify no regression. Check startup/page load, API latency, rendering, database queries, large lists, images/assets, memory, CPU, and network where applicable. Avoid premature optimization and unnecessary dependencies.
