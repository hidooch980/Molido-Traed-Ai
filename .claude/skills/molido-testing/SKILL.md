# MOLIDO TESTING
Discover the existing test commands and frameworks first. Prefer targeted tests for changed areas, then run the full applicable suite before release. Never disable tests, weaken assertions, or call flaky tests PASS without investigation. On failure: reproduce, identify root cause, fix, rerun original and dependent tests, then regression test. Report exact commands and actual results.
