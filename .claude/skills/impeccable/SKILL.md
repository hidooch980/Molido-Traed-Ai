# IMPECCABLE INTEGRATION
Use the official Impeccable installation for the full upstream skill when available. MOLIDO treats Impeccable as the deep visual/UI specialist, not as the release or E2E gate.

Preferred upstream workflow:
- `/impeccable init` for durable product/design context.
- `/impeccable audit` to identify UI problems.
- `/impeccable critique` for deeper design review.
- `/impeccable polish` for final cleanup.
- Use live browser iteration when supported.

Boundary: Impeccable owns visual/UX quality. `molido-human-e2e` owns real user behavior and release evidence.
