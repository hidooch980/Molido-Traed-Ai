# MOLIDO DATABASE
Inspect existing schema and migration conventions first. Preserve data integrity, constraints, indexes, transactions, and rollback paths. Test create/update/delete/read flows, duplicates, invalid input, concurrency where relevant, migrations, backups, and recovery. Never perform destructive production changes without explicit authorization and a recovery path.
