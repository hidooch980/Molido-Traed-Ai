# MOLIDO DEBUG
Reproduce first. Capture exact error and context. Narrow scope using logs, stack traces, network/database state, recent changes, and minimal experiments. Fix the root cause rather than masking symptoms. Retest the original failure and affected dependencies, then run regression checks. Do not claim fixed until reproduced PASS.
