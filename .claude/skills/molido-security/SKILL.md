# MOLIDO SECURITY
Inspect auth/authz, session handling, secrets, input validation, injection risks, API exposure, access control, sensitive data, permissions, dependency risk, logging, and error leakage. Use project-native scanners and tests where available. Do not invent security PASS. Blocking findings stop release until fixed or explicitly accepted by the authorized release owner.
